# Southwestern PIKE

A new public website for the Alpha Omicron Chapter of Pi Kappa Alpha at Southwestern University in Georgetown, Texas.

Open `index.html` through a local web server to preview it. Current officer names and additional chapter photographs should be confirmed before publication.

## Updating officers and events

Edit `content.js` to change officer names or upcoming events. The hero contains a designed placeholder until an approved replacement chapter photograph is supplied.
